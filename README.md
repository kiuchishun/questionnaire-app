# インターン向け Vibe Coding 練習用アンケートアプリ

React + Vite で作った、**提出フォーム + 管理画面**を持つ小規模アプリです。  
インターンのコーディング面接（vibe coding）を想定して、短時間で「仕様理解」「改善提案」「実装力」を見せやすい題材にしています。

## このアプリでできること

- 回答者向けのアンケート入力フォーム
- 送信前の確認画面
- 回答後のサンクス表示
- 管理画面ログイン（パスワード認証）
- 回答一覧の確認、単体削除、全削除
- 満足度の平均値と分布の可視化

> データは `localStorage` に保存されるため、バックエンド不要で動作します。

## 管理画面パスワード設定

管理画面は `VITE_ADMIN_PASSWORD` を使って認証します。

### 開発時

- `.env` 未設定の場合、開発モードではパスワードが `admin` になります。
- 任意の値にしたい場合は `.env` を作成して設定してください。

```bash
VITE_ADMIN_PASSWORD=your_password
```

### 本番時

- `VITE_ADMIN_PASSWORD` が未設定だと管理画面にログインできません。
- ビルド時に必ず環境変数を設定してください。

## 面接練習で使うときの例

- バリデーションを強化する
- 検索・絞り込み・ページングを追加する
- localStorage から API 保存に置き換える
- テスト（ユニット/E2E）を追加する
- UI/アクセシビリティを改善する

## 補足

このリポジトリは「正解実装」ではなく、**改善しながら説明する練習素材**として作っています。  
面接では、実装だけでなく「なぜその設計にしたか」を言語化するのがおすすめです。
