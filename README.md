# アンケート管理アプリ

企業内での簡易アンケート収集を想定した、`React + Vite` 製のフロントエンドアプリケーションです。  
回答フォームと管理画面を備え、バックエンドなしで素早く導入・検証できる構成になっています。

本アプリは、企業のvibe coding面接を想定した実践練習用として作成しました。短時間での要件理解・実装・改善提案の訓練を目的としています。

## 概要

- 回答者向けアンケートフォームを提供
- 回答内容の確認画面と送信完了画面を提供
- 管理者向けログイン付き管理画面を提供
- 回答一覧の閲覧、単体削除、全件削除に対応
- 満足度の平均値と分布を可視化

> 回答データはブラウザの `localStorage` に保存されます。  
> 小規模運用やPoCに適した構成です。

## 想定ユースケース

- 社内イベント・研修後アンケートの回収
- 期間限定キャンペーンの満足度調査
- 新規施策のPoCでのユーザーフィードバック収集
- バックエンド実装前の画面要件確認

## 主な機能

- **回答フロー**: 入力 -> 確認 -> 送信完了
- **管理機能**: パスワード認証、回答一覧、削除操作
- **可視化**: 満足度の平均値と分布表示
- **運用性**: バックエンド不要で即時起動可能

## 管理画面の認証設定

管理画面の認証には環境変数 `VITE_ADMIN_PASSWORD` を使用します。

### 開発環境

- `.env` が未設定の場合、開発時のみデフォルト値 `admin` が利用されます。
- 任意の値を設定する場合は、プロジェクトルートに `.env` を作成してください。

```bash
VITE_ADMIN_PASSWORD=your_password
```

### 本番環境

- `VITE_ADMIN_PASSWORD` が未設定の場合、管理画面にログインできません。
- セキュリティ上、強度の高いパスワードを設定してください。

## 導入時の注意事項

- 本アプリのデータ保存先は `localStorage` です。
- ブラウザ・端末依存のため、共有端末運用や永続保管には不向きです。
- 本番運用では、API連携とサーバー側での認証・保存への置き換えを推奨します。
